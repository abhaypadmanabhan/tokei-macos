### WP-1 addendum — Claude Code (Opus) — 2026-07-27 ~14:40 PT — review follow-up

Independent Codex review marked WP-1 **SHIP WITH FIX** on one MEDIUM finding. The signing fix
itself was verified correct and was not touched. Commits `512fbac`, `9337fc0`.

- **Finding (valid, now fixed):** `verify-app.sh` inferred success from silence. It discarded the
  process exit status and printed `OK` on any early exit unless stderr matched one of five English
  regexes, so a correctly signed binary that exited 1 immediately still let `build-app.sh` exit 0.
  Demonstrated against the pre-fix script: an `exit 0` and an `exit 1` main binary both returned
  **OLD EXIT=0**; both now return **EXIT=1**.
- **Fixes:** positive liveness requirement (the process must be alive at the end of the window);
  exit status captured via `wait` and reported, including signal deaths; headless skip reported
  distinctly and never as `OK`, with `TOKEI_VERIFY_REQUIRE_LAUNCH=1` to make it a hard failure;
  nested executables enumerated rather than hardcoded, with secure-timestamp assertion added.
  Static checks went from 3 hardcoded items to **9 enumerated** — now including Sparkle's
  `Autoupdate`, `Updater.app`, `Installer.xpc` and `Downloader.xpc`.
- **New real bug the stricter gate caught immediately:** both signing modes shared one persistent
  `build/DerivedData`, so the first ad-hoc build after a signed build staged a still-Developer-ID-
  signed `Contents/Helpers/tokei` — a bundle whose helper Team ID differs from the app's, which
  `codesign --verify --strict --deep` passes. Fixed by splitting into
  `build/DerivedData-release` / `build/DerivedData-adhoc`. **This is the residual truth in the
  Bible's "stale DerivedData" hypothesis:** correctly ruled out as the cause of the original
  unlaunchable build (which reproduces from a clean tree), but a genuine defect on mode
  transitions. Verified `release → dev → release` from a clean tree: all three exit 0.
- **Gate proven to fail, not just to pass** (7 cases): GOOD → 0; `exit 1` / `exit 0` / `abort()`
  main binaries → 1; XPC service signed `--timestamp=none` → 1 *while `codesign --verify --strict
  --deep` still exits 0 on it*; `Autoupdate` without hardened runtime → 1; ad-hoc + hardened → 1.
