### Deliberately NOT selected

- **Cross-account dedup.** `seenIDs` is per `parse()` call and Claude does not share message
  IDs across accounts. The 2026-07-27 lessons entry flags "unreachable" as the exact word
  that was wrong about the last bug — so this is recorded as *untested*, not *safe*, and left
  for a dedicated RED-first session.
- **Live credential refresh.** Tokei reads OAuth tokens and never rotates them; refreshing
  would race the Claude CLI's own rotation.

## 3. Work packages

### WP-A · Identity-keyed accounts — `762049e`, `e8906c0`

- **Scope:** `Core/Providers/ClaudeAccount.swift`, `Core/Providers/ClaudeCodeProvider.swift`,
  `Core/Utilities/FileWatcher.swift`, + `Tests/ClaudeUsageTests/`.
- **Done:**
  - `discover()` reads `oauthAccount.accountUuid` from each directory's config JSON and groups
    directories by it. `ClaudeAccount` gains `additionalDirectories` and `accountUUID`;
    `projectsDirectory` → `projectsDirectories`, and both the provider and the watcher iterate
    every directory an identity owns.
  - The config file's location is asymmetric and the asymmetry lands on the account that has to
    merge: the default account's lives *beside* its directory at `~/.claude.json`; every other
    account keeps it inside at `<dir>/.claude.json`. Both shapes are checked.
  - A directory whose identity cannot be read stays on its own — unknown is not a value two
    directories can share.
  - `e8906c0` fixes three defects an adversarial review reproduced against the real `discover()`:
    `detectAvailability()` checking only the canonical directory (reported `notInstalled` while
    `fetchSnapshot()` parsed those same logs), `canonicalDirectory(among:)` sorting by `projects/`
    mtime (one session under a sibling `CLAUDE_CONFIG_DIR` renamed the cooldown file and let the
    app re-hit the usage endpoint inside its own backoff window), and live quota reading only the
    canonical directory's Keychain item.
- **Evidence:** on the real corpus, 3 accounts → 2; merged `tokensToday` 222,029,866 =
  139,075,023 + 82,954,843; `dupKeys=95 corrections=2` unchanged from the `.claude`-alone parse;
  second refresh `hits=639 bytesRead=0KiB`, 7,246 ms → 36 ms — 50276d2's cross-account cache
  survives an account that now carries 639 sources.
- **Rollback:** `git revert e8906c0 762049e` — dependent fix first, same top-down order as §6 (no merge commit; branch retained).
