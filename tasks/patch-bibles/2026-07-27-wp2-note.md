- **Done:**
  - **Shared helper** — new `Core/Network/UsageClientPolicy.swift`: `rateLimitAction(retryAfter:
    attempt:maxAttempts:defaultCooldownInterval:)` (the `Retry-After` early-exit decision),
    `observed(_:at:)` and `replayedFromCache(_:observedAt:)` (the `observedAt` stamp). Free
    functions on an enum plus one small value type — no transport abstraction; clients keep
    their own requests, cooldown files, and error types. Direct unit tests, including the
    `retryAfter == ceiling` boundary.
  - **P1 Cursor retry storm** — `CursorUsageClient` now gives up on the first 429 whose
    `Retry-After` exceeds the 30s ceiling, records the cooldown, and throws `.rateLimited`.
    Short values are still honoured and retried. `maxRetrySleepInterval` deleted from the
    client; the ceiling lives in the policy.
  - **P1 logging** — the fetch path logged *nothing*. Now logs 429 (with `Retry-After` and
    attempt number), 401, and any other non-2xx with its status code, via
    `Logger(subsystem: "ai.padzy.tokei", category: "CursorUsageClient")`. Status codes and
    intervals only; the session cookie and response bodies are never logged (asserted by the
    pre-existing `testPerCookieCooldownIsolation`, which greps every file for the raw cookie).
  - **P2 Antigravity `observedAt`** — cache replay no longer concatenates `" (stale)"`; `source`
    stays `"antigravity-local-rpc"` and the cache's own write time becomes `observedAt`, with
    `confidence: .estimated` as before. The live path stamps `observedAt` too. Cache replay now
    reuses `decodeQuotaWindows` instead of re-deriving the same window construction, which is
    where the two paths had already drifted.
  - **P5 `discoverLogSources()`** — contract chosen and documented on the `LocalLogProvider`
    declaration: **partial failure is absorbed, total failure throws.** Three distinguishable
    outcomes (sources / honest empty / throw). `ClaudeCodeProvider` matches it and carries the
    same rationale on its override. `fetchSnapshot` is untouched — it still reads accounts
    individually and warns per failure.
