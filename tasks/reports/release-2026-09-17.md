  30-day month; "Last 7 days".

- Cursor: accepted lines out of token charts; `observedAt` at the quota response.

  decision, additive snapshot fields (`accountID`, `selector.env`, `quota`, `headlineAccountID`,
  `recommendation.target`, `avoidAccounts`, `validUntil`), MCP descriptions + reader-side expiry.

- UI: −1.4 k lines of duplicate/decorative chrome; rolling live numbers; honest labels.
- Memory/CPU: peak footprint 7.7 GB → 645 MB, RSS 3.0 GB → 0.3 GB on the author's corpus.

## Security review (Astra, `main...dev`)
0 critical, 0 high, 2 medium, 2 low — all four fixed on `dev` (`ddcabfd`) and re-probed in the
final review:
- S01 medium — unbounded JSONL records + quadratic scan in the new Claude loop → 16 MiB record cap
  (one bounded warning, offsets advance), scan cursor.
- S02 medium — inherited: hostile token numbers (1e100, Int.max) trapped the process → range-checked
  conversion, checked arithmetic.
- S03 low — unbounded MCP frames / reflected names → 1 MiB frame cap, names truncated to 128 chars.
- S04 low — SQLite online-backup copy created 0644 (0.8.0's copyItem kept 0600) → 0700 dirs,
  exclusive 0600 destination.
Considered and refuted (with reasoning in `tasks/t13.result.md`): shell execution via selector
paths, env-key injection, token-derived accountIDs, credential text in warnings, hostile MCP
params reaching disk, snapshot path disclosure, torn SQLite copies, unsalted hashes
(domain-separated by design), registered-root traversal, new network destinations.

**Accepted risk:** `accountID` is a domain-separated but unsalted hash of a provider identity —
a correlatable pseudonym, not anonymity, by design (documented in docs/08).

## Known / not fixed
- Final review (r15, SHIP-WITH-NOTES): the MCP transport fixes (S03) first introduced a pipe
  deadlock and were replaced by a POSIX bounded reader with real-pipe subprocess tests. One
  should-fix stays open: an overflow warning is not propagated when a *provider-level*
  aggregation across accounts saturates (requires > 9.2 × 10¹⁸ tokens summed across accounts;
  per-record, per-component and per-account overflow do warn).
- Default Claude account on the author's machine has an expired OAuth token; Tokei never
  refreshes tokens. Row reads `expiredCredentials` until `claude` runs once from `~/.claude`.
- A Codex session file straddling a re-login belongs to the identity it started under.
- Strict SwiftLint still red (360 vs 380 in 0.8.0).
- `tasks/brand/*.png`, `tasks/handoff/*.png` are deleted in the working tree but not committed
  (pre-existing; owner's call).
