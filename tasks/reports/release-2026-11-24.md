# Release report: Tokei 0.14.0 "Sign-ins" (2026-11-24)

**State: SHIPPED.** App 0.14.0 (build 14) is notarized, published on GitHub, and live on the Sparkle update feed. Abhay
authorized the promotion and release (t923u). Changes: CHANGELOG `[0.14.0]`. User-facing notes:
`tasks/reports/release-notes-0.14.0.md`.

## What shipped
- **SuperGrok pool** (#73). The pool is read from the Grok CLI's own billing call. A pool shared with a Cursor Super
  plan is counted once. When Cursor 3.x's encrypted sign-in cannot be read, Tokei now says why.
- **Official sign-ins, opt-in** (#74). Copilot uses GitHub billing: counts and dollars only. OpenCode Go shows its
  5-hour, weekly and monthly windows. Pasted keys stay in Tokei's own Keychain.
- **Privacy** (#72). Parser warnings no longer contain directory paths.
- **Release tooling.** `make-dmg.sh` falls back when Finder does not answer. That fallback was exercised in this
  release.
- **Test** (#75). A flaky teardown in `LowPowerSyncTests` is fixed.

## Known gate gaps, accepted for this release
- **Lint.** `swiftlint --strict` reports 683 violations. All of them predate this release (683 on origin/dev before
  #72–#74 as well), and the count stays at the ratchet. Release mode does not make lint stricter: it is the same
  command.
- **Format.** In release mode the gate fails because swiftformat is not installed, and the repo has no
  `.swiftformat` config. The gate has never run on any release.

## Security review: accepted lows
- Keychain items use the default accessibility setting, which keeps them readable only by the app that saved them.
- The GitHub login is validated with a regex that ends in `$` rather than `\z`. The login comes from api.github.com and
  is percent-encoded into a path on that same host.
- xAI's plan name is shown as-is in a UI warning. It is not written to the agent snapshot.
