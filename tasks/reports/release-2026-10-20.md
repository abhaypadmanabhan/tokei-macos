## Measurement notes
- The first Debug-build CPU proof (14.6 %) was a Debug build under live agent load, not comparable.
- Two early A/B attempts were invalid: an ad-hoc-signed Release build cannot load its framework
  under the hardened runtime (died at launch), and a hidden launch never starts syncing (see Known).
- One busy A/B ran beside builds and reviewers (13.5 % vs 9.9 %); the clean back-to-back pair and a
  profile replaced it. The profile located the cost: per-record `calendar.startOfDay` in allocation.

## Security review (Claude, `main...dev`) — 0 critical/high/medium, 4 low
- L1 hostile probe numbers could crash Tokei — fixed (`76284bc`, `139d06e`).
- L2 price overflow to infinity — fixed, cap $100,000 per million (`76284bc`, `139d06e`).
- L3 `codex` resolved from user-writable folders before Homebrew — accepted (same-user attacker).
- L4 probe on by default — deliberate (bible decision); documented in the release notes.
