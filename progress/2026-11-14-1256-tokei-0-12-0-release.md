## Outcome

Tokei 0.12.0 is out to every user through the in-app updater, GitHub and the redesigned website. It turns the
flat-rate AI plans people pay for into a game: a daily burn goal, streaks, records, 13 badges, a ranking of their own
agents and a weekly share card, with at most two quiet notifications a day when a plan window is about to reset
with plenty left. Only plan usage counts; pay-per-token spend never does. Agents can now be connected in one click
(Claude Code, Codex, Cursor), see "use it or lose it" windows through a new MCP tool, and read usage in a summary
82 % smaller. The menu bar item no longer redraws on every change, cutting idle CPU. The website is a dark,
cinematic page led by a generated ember film and rebuilt from the real app's screens.

The run was orchestrated in Herdr: Codex GPT-6.1-Sol wrote the engine and agent lanes, Claude Opus 5.5 the UI and
website, each reviewed by the other family. Reviews caught two blockers before release (record notifications on
every refresh; "Connect Claude Code" writing a file Claude never reads). Release waited on Apple's expired developer
agreement overnight and on the Sparkle key living on the M4, both resolved by Abhay at midday.
