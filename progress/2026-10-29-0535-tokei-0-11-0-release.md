## Outcome

Tokei 0.11.0 is out to every user through the in-app updater and the website. It now reads Codex's newer
compressed session logs, so Codex value is right again, prices Claude's longer cache correctly, and adds
token counts for Antigravity and GitHub Copilot. Overview has a new Cost view with today's dollars, a daily
dollar chart and dollars per tool, and every quota bar says whether it will last until it resets. The app
opens straight onto your last numbers, uses far less disk, keeps its files private, and gives coding agents
a richer, safer connection. Small capital-letter labels are gone from the app and the website.
