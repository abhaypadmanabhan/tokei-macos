# Zstandard decoder fixtures

Rebuild with `python3 AIUsageDashboard/Tests/Fixtures/Zstd/generate.py` from the repo root.
Generated with Homebrew zstd 1.5.7. No real session content is included. Every binary is
at most 16 KiB. `generate.py` is excluded from the test target in project.yml.

- `raw`: seeded random bytes; zstd emits a raw block; expected bytes are `raw.bin`.
- `rle`: 300,000 copies of R; compressed first block followed by RLE blocks.
- `compressed`, `checksum`, `high`: 5,000 synthetic records; zstd levels 3, 9 and 19,
  no checksum / checksum / checksum. Expected bytes are constructed independently in
  ZstdDecoderTests. Several blocks exercise entropy-table reuse and repeat offsets.
- `multi`: `compressed` followed by the independently compressed `tail` frame.
- `stress`: the first 2,048 synthetic bytes; every byte is mutated and every truncated
  prefix is decoded under XCTest. Accepted mutations must preserve the original bytes.
- `window`: 50,000 synthetic bytes, 1 KiB window and no content-size field; exercises
  circular history and cross-block matches without a known output length.
- `truncated`, `corrupt-*`: copies with a missing byte or individual bit flips in
  magic, header, literal/sequence data and checksum. Every named malformed fixture throws.
- `oversized-window`: handcrafted 256 MiB window descriptor; rejected before allocation.
- `output-limit`: handcrafted unknown-size frame of RLE blocks that expands past the
  256 MiB file cap. `multi-output-limit` reaches the cap exactly, then appends another
  valid frame. Streaming tests assert that neither delivers more than the file cap.
  `limit-tail` is that extra one-byte frame, generated by zstd.

The streaming callback receives provisional blocks: callers must discard any parsed
result if decoding ultimately throws (including a checksum failure in a later frame).

The opt-in ZstdRealLogsOracleTests reads only regular `.codex/sessions/**/*.jsonl.zst`
files, hashes Swift's streaming output and independently hashes `zstd -dc` output.
It never writes real logs, stores decoded real content, or prints their contents.
Timing includes the Swift output hashing callback and excludes the external decoder.
